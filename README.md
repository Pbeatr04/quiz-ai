# Quiz AI – Aplicação Mobile com Backend

Aplicação desenvolvida com foco em criação e execução de quizzes, utilizando frontend mobile e backend integrado para processamento de dados.

## Sobre o projeto

O Quiz AI é uma aplicação que permite a criação e execução de perguntas e respostas, simulando um sistema de quiz interativo. O projeto foi desenvolvido com separação entre frontend e backend, aplicando conceitos reais de desenvolvimento.

## Objetivo

- Praticar desenvolvimento de aplicações completas (full stack)
- Trabalhar integração entre frontend e backend
- Aplicar lógica de programação em cenários reais
- Organizar código em estrutura de projeto profissional

## Tecnologias utilizadas

### Frontend (Mobile)
- React Native
- Expo

### Backend
- Python
- Flask

## Funcionalidades

- Criação de quizzes
- Exibição de perguntas e respostas
- Interação do usuário com o quiz
- Integração entre mobile e backend

## Estrutura do projeto

- `quiz-mobile/` → aplicação mobile (frontend)
- `app-flask-pdf/` → backend em Python (Flask)
- `uploads/` → arquivos gerados/utilizados
